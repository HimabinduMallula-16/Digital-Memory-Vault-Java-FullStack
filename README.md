# Digital Memory Vault

Digital Memory Vault is a Java Full Stack web application developed using Java, JSP, Servlets, JDBC, MySQL, Bootstrap, HTML, CSS, and JavaScript.

The platform allows users to securely store memories, notes, files, and future messages in digital vaults that remain locked until a selected future date.

## Features

### User Authentication
- User Registration
- Login System
- Session Management
- Logout Functionality

### Memory Vault Management
- Create Memory Vault
- Upload Files and Images
- Future Unlock Date
- Password Protected Vaults
- Privacy Settings

### Timeline System
- Locked / Unlocked Memories
- Countdown Timer
- Timeline View

### Search and Filter
- Search Memories
- Filter by Category

### Dashboard Features
- Total Vault Statistics
- Upcoming Unlock Tracking
- Archive Statistics

### User Profile
- Upload Profile Picture
- Theme Toggle
- Profile Management

### Additional Features
- Favorites System
- Archive Memories
- Responsive UI
- File Upload System
